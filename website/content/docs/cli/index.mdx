title: CLI 总览
description: 两个 CLI 的分工、共同约定与命令速查
---

fuyubot 有两个命令行程序，职责严格分离，**都不编译、不打包插件**——编译归插件作者自己的工具链
（`cargo build`、`cl /LD`、`gcc -shared`）。

| CLI | 干什么 | 二进制 |
| --- | --- | --- |
| [`fuyubot`](./fuyubot.mdx) | 跑框架：`init` / `run` / `status` / `stop` / `config` / `plugin` | `fuyubot(.exe)` |
| [`fuyubot-sdk`](./fuyubot-sdk.mdx) | 写插件：脚手架 / 生成绑定 / 查 TDLib 方法 / 静态检查 | `fuyubot-sdk(.exe)` |

`fuyubot` 在运行时包里（旁边带着 `tdjson` 和内置插件目录 `plugins/`），`fuyubot-sdk` 在
`fuyubot-sdk-<系统>-<架构>.zip` 里（不需要 `tdjson`）。从源码跑的等价写法是把子命令接在 `--` 之后：

```bash
cargo run -q -p fuyubot-cli     -- run --replay examples/replay/new_message.json
cargo run -q -p fuyubot-sdk-cli -- abi-version
```

## 共同约定

| 项 | 约定 |
| --- | --- |
| `--config <文件>` | 默认 `fuyubot.toml`；项目根 = 配置文件所在目录，`plugins/`、`data/`、`.fuyubot/` 都相对它 |
| `--plugin-dir <目录>` | 覆盖配置里的 `[plugins].dir` |
| 退出码 | `0` 成功；非零是失败（`fuyubot-sdk check` 非零 = 宿主会拒绝加载） |
| 凭据 | **只走环境变量或交互式输入**，任何命令都不把它们写进文件（`TG_API_ID` / `TG_API_HASH` / `TG_BOT_TOKEN`） |
| 输出语言 | 中文；`status` / `stop` 是给人看的，不要拿去解析（没有 `--json`） |

## 命令速查

```text
fuyubot init [--dir .] [--name 名字] [--api-id N]      生成项目
fuyubot run  [--config …] [--plugin-dir …] [--background] [--replay 文件]
fuyubot status | stop [--config …]                     实例状态 / 优雅停止
fuyubot config [--config …]                            打印生效配置（含默认值）
fuyubot plugin list | install <路径>                    插件目录管理

fuyubot-sdk init <名字> --lang <rust|c|cpp|python|js>
fuyubot-sdk codegen --lang <…> [--dir …]               刷新 ABI 绑定
fuyubot-sdk check <路径>                               静态查导出符号（不加载）
fuyubot-sdk abi-version | td-methods [--filter s] | td-method <名字>
```
