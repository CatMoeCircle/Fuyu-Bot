---
title: 环境变量
description: 每个变量的读取者与作用
---

| 变量 | 谁读 | 作用 |
| --- | --- | --- |
| `TDLIB_TD_API_TL` | `fuyubot-tdlib-sys/build.rs`（**构建期**） | 显式指定 `td_api.tl`，优先级最高（完全离线构建就这么干） |
| `FUYUBOT_TDLIB_VENDORED_CACHE` | 两个 `build.rs`（**构建期**） | 缓存根：`td_api.tl` 与 vendored 动态库都放这儿。**必须绝对路径**（build.rs 的 CWD 是各自的 crate 根） |
| `FUYUBOT_TDLIB_RELEASES_REPO` | `build.rs`（**构建期**） | 覆盖 `[package.metadata.fuyubot] releases-repo`（默认 `xiaoqvan/Fuyu-Bot`） |
| `TDLIB_TDJSON_PATH` | 加载器（**运行期**） | tdjson 的目录或文件，查找优先级 1；嫌四级排查麻烦就直接设它 |
| `TG_API_ID` | `fuyubot run` | TDLib api_id（**不是**秘密）。也顺手带进自动生成的配置 |
| `TG_API_HASH` | `fuyubot run` / 集成测试 | api_hash，**凭据**。只认环境变量或交互式输入 |
| `TG_BOT_TOKEN` | `fuyubot run` / 集成测试 | bot 账号的 token；有值就不问 Bot Token，后台运行也能登 |
| `FUYUBOT_NAME` | `fuyubot run` 的自动 init | 自动生成配置时的 `[bot].name`（默认 `fuyubot`） |
| `FUYUBOT_SDK_PATH` | `fuyubot-sdk init` | 指向**放着 SDK crate 的目录**（仓库里就是 `crates/`）；生成的插件用 `path = …` 依赖它，因为那两个 crate 还没发到 crates.io |

## 构建期 vs 运行期

<Callout type="info">
  **`FUYUBOT_TDLIB_VENDORED_CACHE` 只在构建期读。** 运行期用的是构建时烤进二进制的路径（`cargo:rustc-env` 写进去的 `FUYUBOT_TDLIB_VENDORED_DIR`——那是构建产物，不是让你设的变量）。运行时动态库最终由加载器的四级优先级决定，**不读** `FUYUBOT_TDLIB_VENDORED_CACHE`。
</Callout>

缓存根是一串候选，顺序即优先级：

```text
FUYUBOT_TDLIB_VENDORED_CACHE
  → $CARGO_HOME/fuyubot-tdlib-vendored
  → 项目本地 <工作区根>/.tdlib-cache
```

前两档写不进去时会退到项目本地那档；**全都写不进去**才退到 `$OUT_DIR`——那个目录每次重跑构建脚本都会被清空，于是下次构建会重新下载（构建脚本会明确警告）。仓里的 `.cargo/config.toml` 已经把项目本地那档指好了。

```powershell
# 要临时换缓存位置才手写；必须绝对路径
$env:FUYUBOT_TDLIB_VENDORED_CACHE = "F:\Rust\FuyuBot\.tdlib-cache"
```

## 凭据

<Callout type="warn">
  **凭据一律不落盘**（`AGENTS.md` 约束 41）：`api_hash`、Bot Token、手机号、验证码、两步验证密码不得写进仓库任何文件、`fuyubot.toml`、测试夹具或日志。只允许两个来源——**环境变量**（上表那几个）与**交互式输入**（`fuyubot run` 问）。
</Callout>

- `api_id` **不是**凭据，写进配置没问题（`[telegram].api_id`）。
- `api_hash` 在配置里根本没有字段；写了也被忽略，运行时会改用 `TG_API_HASH` 或提问。
- 后台运行没有 stdin：没有 session、也没 `TG_BOT_TOKEN` 时会直接失败，先把前台 `run` 登一次。

## 只在自动 init 那一次生效

`FUYUBOT_NAME` 与 `TG_API_ID` 只在 `run` **自动生成配置**时被读（缺 `fuyubot.toml`，或 `--config` 指向默认文件名而它不存在）。配置已存在就不参与——否则每次跑都会覆盖你手写的名字。
